# 求职流程管理看板 UI 设计与交互实现规范（AI Coding Prompt 版）

> 本文件是直接给 AI coding 阅读的 UI/交互规范，不是给设计师欣赏的概念稿。
> 
> 目标：让 AI 用**简单、稳定、容易实现**的技术，产出一个**漂亮、精致、简约、偏粉马卡龙色系**的 PC 端求职流程管理系统。
> 
> 必须与产品 PRD 保持一致：
> - 页面包含 `/dashboard`、`/calendar`、`/companies`
> - 有全局右侧详情 Drawer
> - 支持 AI 解析，也支持手动填写、手动编辑
> - 界面适合女生使用，柔和但不幼稚，专业但不冷硬

---

# 1. 总体设计目标

请实现一个 **高颜值 PC 端 Web 应用**，产品名：**求职流程管理看板 Job Hunt Flow Board**。

整体气质要求：
- 精致
- 简约
- 轻盈
- 温柔
- 偏粉色马卡龙
- 适合女生
- 不幼稚、不廉价、不花哨
- 像一个真正能拿去面试展示的产品，而不是普通后台

设计参考气质：
- 温柔版效率工具
- 少女感但克制
- 像“奶油粉色系的 Linear / Notion 风格”

必须避免：
- 黑灰蓝传统后台风
- 过于理工男审美
- 过多复杂图表
- 过多渐变和光效
- 过度卡通化
- 复杂难实现的 3D 动画或粒子特效

---

# 2. 实现优先级原则

本项目优先级：
1. **先保证界面漂亮且结构清晰**
2. **再保证交互简单且稳定**
3. **最后再加轻量动效**

必须使用容易实现的方案：
- 普通卡片布局
- 表格 / 列表 / 时间轴 / Drawer
- 简单 hover / active / scale 动效
- 简单 SVG 或 lucide-react 图标
- 简单 CSS 渐变

不要使用：
- 难维护的复杂 canvas 动画
- 很重的图形库
- 很复杂的自定义绘图
- 很夸张的弹跳动画

# 4. 配色规范（更偏粉马卡龙）

整体配色必须比旧版更偏粉、更柔和。

## 4.1 页面背景色
- `app-bg`: `#FFF7FB`  
  整体主背景，极浅粉色
- `app-bg-secondary`: `#FFFDF7`  
  局部渐变辅助背景，可和浅黄混合
- `surface-bg`: `#FFFFFF`  
  卡片主体白色
- `soft-panel`: `#FFF1F7`  
  浅粉面板底色
- `warm-panel`: `#FFF8E8`  
  浅黄色面板底色
- `cool-panel`: `#F8F5FF`  
  浅紫粉面板底色

## 4.2 主色
- `primary`: `#F3AFCB`  
  主粉色，所有主要按钮和高亮状态首选
- `primary-hover`: `#EA9CBE`
- `primary-strong`: `#DD85AE`

## 4.3 辅助色
- `secondary-pink`: `#FFD8E8`
- `secondary-yellow`: `#FFF0B8`
- `secondary-lilac`: `#E9D8FF`
- `secondary-peach`: `#FFE2D6`
- `secondary-mint`: `#DDF5E8`

## 4.4 文本色
字体不要花哨，使用正常中文字体，文字颜色略深，和背景和谐但对比足够。

- `text-primary`: `#47384A`
- `text-secondary`: `#6F6172`
- `text-tertiary`: `#9B8F9D`
- `text-on-primary`: `#FFFFFF`

## 4.5 边框与阴影
- `border-light`: `#F3E4EC`
- `border-strong`: `#E8D4DE`
- `shadow-soft`: `0 8px 24px rgba(214, 164, 187, 0.10)`
- `shadow-hover`: `0 12px 30px rgba(214, 164, 187, 0.16)`

## 4.6 状态色
- `success`: `#8ECFAF`
- `warning`: `#F3C96B`
- `danger`: `#E58CA4`
- `info`: `#A8BDF3`
- `neutral`: `#DDD6E3`

## 4.7 状态使用规则
- 已通过：浅绿色底 + 深绿色文字
- 当前进行中：主粉色底 + 白字
- 未开始：浅灰紫底 + 次级文字
- 未通过：浅红粉底 + 深粉文字
- 笔试 / 测评：浅黄色底
- 面试类：浅粉紫底或浅蓝紫底

# 5. 字体与排版规范

## 5.1 字体
不要用花里胡哨的字体。

统一使用：
- 中文：`PingFang SC`, `Microsoft YaHei`, `Noto Sans SC`, `system-ui`
- 数字和英文也跟随系统字体即可，不强制用 Inter

## 5.2 字号层级
- 页面大标题：`28px / 700`
- 区块标题：`18px / 700`
- 卡片标题：`16px / 600`
- 正文：`14px / 500`
- 说明文字：`12px / 500`

## 5.3 间距规范
- 页面左右 padding：`32px`
- 页面顶部 padding：`28px`
- 卡片内 padding：`20px ~ 24px`
- 模块间距：`20px / 24px / 32px`
- 行高：正文 `1.5`

## 5.4 圆角
- 大卡片：`24px`
- 中小卡片：`20px`
- 按钮：`14px ~ 18px`
- 小标签：`999px` 胶囊

- 圆角：`28px`

- 导航项：
  - Dashboard
  - Calendar
  - Companies
- 底部放 AI Copilot 小猫入口或头像入口

选中态：
- 淡粉底色
- icon 和文字略微变深
- 整个导航按钮 scale 到 `1.04`

hover 态：
- 背景稍亮
- 阴影轻微增强

## 6.3 顶部 Header
- 左侧：页面标题 + 一句小副标题
- 右侧：日期、小头像、可选搜索框
- Header 要薄，轻，不要有重边框
- 背景尽量通透，不要像传统后台顶部栏

# 8. Dashboard 页面设计

## 8.1 页面布局
使用 `12 栏布局`：
- 左侧 `8 栏`：时间维度流程表格
- 右侧 `4 栏`：明日提醒 + 今日动向 + AI Copilot
- 底部或左下：我的简历小卡片

## 8.2 顶部欢迎区
内容：
- 标题：`今天也离理想 offer 更近一点`
- 副标题：`把面试、流程和投递节奏整理得更轻松一点`
- 右上角放一个日期 pill

样式：
- 纯文字 + 很少量装饰
- 可在标题旁边放一个很小的星星或花朵 icon
- icon 要简单，建议用 lucide-react 或简单 SVG

---

## 8.3 时间维度流程表格（主页主模块）

这是页面最核心区域，必须做得最漂亮。

### 外观要求
- 放在一张大白卡片中
- 卡片标题：`未来 7 天流程安排`
- 标题右侧放 tabs：`今日 / 明日 / 本周`
- 表格使用浅分隔，不要传统重线框表格
- 卡片顶部可有一条极淡的粉到黄渐变线作为装饰

### 表格列
- 日期
- 时间
- 事件类型
- 公司
- 部门
- 岗位
- 当前状态
- 关联简历
- 操作

### 行样式
- 行高：`60px ~ 68px`
- hover：背景变为极浅粉紫色
- hover 时轻微上浮 `translateY(-1px)`
- 当前选中时：边框更明显、shadow 略增强
- 点击整行：打开 Drawer

### 单元格视觉规则
- 事件类型：胶囊标签
  - 一面/二面/HR面：浅粉紫
  - 笔试/测评：浅黄
  - Offer 沟通：浅绿
- 当前状态：柔和小标签
  - 待参加
  - 已完成
  - 已通过
  - 未通过
- 关联简历：显示简历名称小标签，没有则显示“未关联”浅灰字

### 操作区
- 查看详情：小型圆角 icon 按钮
- 标记完成：小型次按钮
- 编辑：建议增加一个铅笔 icon 按钮，保证手动编辑入口明显

### 图标建议
优先使用 lucide-react：
- 查看详情：`Eye`
- 编辑：`Pencil`
- 标记完成：`Check`
- 链接：`Link`

不要设计复杂图标，不要自定义大量图形。

## 8.4 明日 AI 提醒卡片

### 目标
视觉上要轻巧可爱，但实现简单。

### 外观
- 背景：浅粉黄渐变 `linear-gradient(135deg, #FFF7D8, #FFF3FA)`
- 左上角：小猫头像 icon
- 右上角：铃铛 icon
- 标题：`明日提醒`
- 内容：一句自然语言提醒

### 小猫 icon 设计要求（必须简单易实现）
不要做复杂动画角色。

推荐实现方式二选一：
1. **简单 SVG 小猫头像**：圆脸 + 两只耳朵 + 两个眼睛
2. **emoji + 小圆底**：🐱 放在浅粉圆形背景里

推荐优先方案：简单 SVG，因为更统一。

### 小猫动效（简单版）
- 默认：轻微呼吸 `scale(1 -> 1.03 -> 1)`
- hover：上浮 `-2px`
- AI 处理中：轻微左右晃动或轻微跳一下

不要实现复杂眨眼骨骼动画。

### 空状态文案
- 如果明天没有安排：
  `明天暂无流程安排，可以安心休息一下。`

## 8.6 我的简历卡片

### 外观
- 小卡片即可，不做独立页面
- 标题：`我的简历`
- 副标题：`放 2~3 份常用版本就够了`
- 背景可以偏白或极浅粉

### 列表项设计
每份简历做成一个小行卡片：
- 左侧：文件图标 / PDF 小图标
- 中间：
  - 简历名称
  - 标签（产品 / 运营 / 算法 / 通用）
  - 上传时间
- 右侧：
  - 预览按钮
  - 删除按钮

### 图标建议
- 文件：`FileText`
- 预览：`Eye`
- 删除：`Trash2`
- 上传：`Upload`

### 空状态
- 一个简洁的小文件夹图标
- 文案：`先放一份简历进来吧`

### 交互要求
- 支持上传 PDF
- 支持预览 Dialog
- 支持删除
- 支持在详情 Drawer 中被关联到岗位

## 8.7 AI Copilot 卡片

这是视觉亮点区域，但必须简单好实现。

### 外观
- 大卡片
- 背景：非常淡的粉紫渐变
- 左上：标题 `AI Copilot`
- 标题旁边：小猫 icon
- 卡片整体要比其他卡片略精致一些，但不要过度复杂

### 小猫 icon 规则
- 统一使用和“明日提醒”里同一种小猫形象
- 尺寸：`28px ~ 34px`
- 默认轻微呼吸
- 点击快捷按钮时轻微放大 `1.06`

### Copilot 输入区
- 一个多行输入框
- placeholder：
  `粘贴面试邮件、JD 或面试转录，我来帮你整理 ✨`
- 输入框圆角：`18px`
- 背景：偏白，边框很浅

### 快捷按钮
下方固定 4 个按钮：
- 解析面试邮件
- 解析 JD
- 生成面试题
- 生成复盘

按钮样式：
- 胶囊按钮
- 浅粉底 / 浅紫底
- 当前激活按钮略微放大
- hover 时背景稍微变深

### 输出区
- 不做真实聊天界面
- 做成“结果卡片列表”
- 每个结果卡片包含：
  - 标题
  - 小标签
  - 结构化内容

例如：
- 解析 JD 结果：关键词 chips + 能力要求列表
- 面试题结果：3~5 条卡片列表
- 复盘结果：3 个小块（问题 / 回答 / 建议）

### Loading
- 显示 3 个柔和跳动的小圆点
- 小猫轻微上浮或轻微摆动
- 不要使用重型 loading 动画

# 9. Calendar 页面设计

这个页面是时间维度的第二种视图，和主页表格共享同一份事件数据。

## 9.1 页面目标
让用户用月视图快速看到：
- 面试
- 笔试
- 测评
- HR 面
- Offer 沟通

## 9.2 页面布局
- 上方：标题 + 月份切换
- 左侧或上方：月视图日历
- 下方或右侧：选中日期的事件列表

## 9.3 日历外观
- 采用干净的月视图
- 每个日期格子要有足够留白
- 有事件时，用小胶囊标签或 1~2 条小色条表示
- 不要在一个格子里塞太多文字

## 9.4 颜色规则
- 面试类事件：浅粉紫小标签
- 笔试 / 测评：浅黄小标签
- Offer：浅绿小标签

## 9.5 交互
- 点击日期：右侧展示当日事件列表
- 点击事件：打开 Drawer
- 日期格 hover：背景轻微变亮
- 提供“新增事件”按钮

## 9.6 手动编辑入口
必须支持：
- 手动新增事件
- 手动编辑时间、类型、公司、部门、岗位、链接、状态
- 删除事件

建议实现方式：
- 点击“新增事件”或“编辑事件”后，弹出轻量 Dialog 表单
- 不要做复杂页面跳转

## 10.5 流程节点样式

建议交互：

- 每条岗位流程条右侧有更多菜单 `MoreHorizontal`
- 点击节点或流程条都可以进入 Drawer 编辑

# 11. 全局右侧 Drawer 设计

这是最核心的详情承载区。

## 11.1 Drawer 外观
- 从右侧滑出
- 宽度：`440px` 左右
- 背景接近纯白
- 左侧大圆角
- 顶部固定，内容区滚动
- 关闭按钮为圆形 icon button

## 11.2 Drawer 内容结构
按以下顺序布局：

### A. 顶部概览区
- 公司名称（主标题）
- 部门 + 岗位（副标题）
- 当前流程状态标签
- 当前阶段时间
- 面试会议链接按钮
- 编辑按钮

### B. 基础信息编辑区
字段：
- 公司
- 部门
- 岗位
- 当前状态
- 时间
- 会议链接

要求：
- 默认是展示态
- 点击“编辑”后切换为表单态
- 必须能保存 / 取消

# 13. 微交互规范

## 13.1 hover
- 卡片 hover：上浮 2px + 阴影略增强
- 按钮 hover：背景略变深
- 节点 hover：scale `1.02`
- 导航项 hover：背景胶囊变亮

## 13.2 active / selected
- 当前导航项：scale `1.04`
- 当前激活的 Copilot 快捷按钮：scale `1.03`
- 当前选中的卡片或表格行：边框加深 + 阴影增强

## 13.3 点击模块变大一点
所有主要卡片在激活时：
- `transform: scale(1.01)`
- `box-shadow: shadow-hover`
- 只允许非常轻的放大，避免跳动

## 13.4 loading
- 3 个浅粉小圆点跳动
- 小猫轻微上浮或晃动
- 不要旋转菊花 loading

## 13.5 空状态文案
文案要温柔、克制、可爱一点，但不能过度拟人。

示例：
- 简历为空：`先放一份简历进来吧`
- 明天无安排：`明天暂无流程安排，可以安心休息一下。`
- 公司未投递：`还没有在这家公司开始流程`
- 暂无面试题：`先解析 JD，再生成更贴合的面试题`
